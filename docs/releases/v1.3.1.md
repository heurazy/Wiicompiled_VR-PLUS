# Wiicompiled VR PLUS v1.3.1 — OpenXR stability

This maintenance release addresses the VR regressions reported in [issue #10](https://github.com/heurazy/mario-kart-wii-VR-port/issues/10) and broadens runtime selection while retaining the character body IK from v1.3.

## Fixes and improvements

- **VDXR stutters:** optional controller-model loading no longer attempts to initialize OpenVR on non-SteamVR runtimes. The supplied log contained 3,390 failed initialization attempts; that per-frame retry loop is removed.
- **SteamVR session safety:** native controller models reuse an existing OpenVR interface when available. Model loading no longer initializes or shuts down a second VR client that could interfere with OpenXR input or focus.
- **Kart stability with frame interpolation:** camera and object transforms are brought into the same seated reference frame before interpolation, keeping the kart rigid during camera movement and turns. Head tracking remains applied at the headset's predicted display time.
- **Menu stability:** VR menus use a stable native game image rather than interpolating menu draws, while the headset presentation continues updating independently of the 60 Hz game simulation.
- **Active OpenXR runtime by default:** new configurations use the system's active runtime, including SteamVR or Virtual Desktop's VDXR. **F10 → Use SteamVR (next launch)** remains an explicit override. Existing explicit SteamVR preferences are preserved; turn that checkbox off to use another active runtime.
- **Quest 3 controller fallback on PC:** the same textured Touch Plus models used by the standalone Quest version are available on desktop, with animated buttons/sticks and tutorial landmarks. SteamVR's device models take priority when available. The installer and portable build include the required model resources.

## Downloads and upgrading

- **WiiCompiled-Setup.exe** — Windows installer with the integrated Wheel Wizard launcher.
- **WiiCompiled-VR-Portable-v1.3.1.zip** — complete portable Windows bundle with Wheel Wizard, setup and launch script. Extract the whole archive.
- **WiiCompiled-VR-Quest3-v1.3.1.apk** — standalone Quest app and local game-build tools.
- **SHA256SUMS.txt** — checksums for these three downloads.

Use your own clean PAL `RMCP01` Mario Kart Wii disc image. No ROM, Nintendo game assets or translated game executable is distributed. Windows users must run setup/rebuild to apply the runtime changes; Quest users must rebuild their local games with the updated app's game kit. Keep your saves and configuration when updating. Quest frame interpolation remains disabled.

## Validation

Windows products compile and both generated dispatch registries validate. The configuration/model-connection checks and 52 targeted renderer tests pass, including camera-turn stability and 72/90/120/144 Hz interpolation timing. The user confirmed the corrected PC test build works. The Quest APK is rebuilt and its package contents checked; these maintenance changes have not received a separate Quest headset test.
